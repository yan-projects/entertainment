# Pickleball Playbook

A responsive beginner guide to pickleball with an interactive court, rules, scoring explanations, and a quick quiz.

## Preview

Open `dist/index.html` in a browser. The site uses plain HTML, CSS, and JavaScript, with no build step or dependencies.

## Files

- `dist/index.html`: complete website.
- `assets/pickleball-rules-rednote.png`: AI-generated rules infographic for social sharing.
- `.openai/hosting.json`: existing Sites deployment configuration.

Rules reference: [USA Pickleball](https://usapickleball.org/rules/summary/). The guide describes standard side-out scoring.
